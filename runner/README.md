# Rail Runner (static demo)

Three-lane endless runner: Canvas 2D, zero dependencies, zero asset files.
This folder is a published copy so the game can be played from the same site as
the Forbidden City scene.

- Play: <https://gubao-tian.github.io/forbidden-city-3d/runner/>
- Source, tests and design notes: <https://github.com/Gubao-tian/rail-runner>

**Controls** — `↑` / `W` / `Space` jump, `↓` / `S` slide, `←` `→` / `A` `D` lanes,
`1` `2` `3` / `Q` use item, `Esc` pause. On touch: swipe up/down/left/right, tap to jump.

Everything is drawn with Canvas 2D and synthesised with WebAudio at runtime —
there is not a single image or audio file in here (see LICENSES.md).
